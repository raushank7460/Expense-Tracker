# 🚀 Vercel Deployment Guide — SpendFlow (Frontend + Backend, Single Project)

Yeh guide aapko sikhayegi ki **ek hi Vercel project me frontend + backend** dono ek saath deploy kaise karein — GitHub se push karo, Vercel pe select karo, deploy ho jao!

---

## 📁 Project Structure (Vercel ke liye taiyar)
```
Expense-Tracker/               ← Root (GitHub repo root)
├── api/
│   └── index.js               ← Vercel Serverless Function (backend entry point)
├── backend/                   ← Express backend source code
│   ├── config/
│   ├── controllers/
│   ├── middleware/
│   ├── models/
│   ├── routes/
│   └── server.js
├── frontend/                  ← React/Vite frontend
│   ├── src/
│   └── dist/                  ← Built output (generated by Vercel build)
├── vercel.json                ← Vercel routing config (1 file, does everything)
└── package.json               ← Root package.json with all dependencies
```

---

## ⚡ How It Works
- **Frontend** → Vercel builds `frontend/` using Vite → serves static files from `frontend/dist`
- **Backend** → Vercel runs `api/index.js` as a **Serverless Function** → handles all `/api/*` requests
- **Routing** → `vercel.json` routes `/api/*` → serverless function, everything else → SPA `index.html`
- **No separate URL needed** — frontend calls `/api/...` (relative URL) which Vercel auto-routes!

---

## 📋 Pre-requisites
1. **GitHub Account** with this repo pushed.
2. **Vercel Account** → [vercel.com](https://vercel.com) (GitHub se Sign In karein).
3. **MongoDB Atlas** → Free cluster URL (`mongodb+srv://...`).
   - Atlas me **Network Access** → Add IP → `0.0.0.0/0` (Allow from Anywhere) karna zaroori hai.

## 🚀 Step-by-Step Deployment

### Step 1: GitHub pe Push Karein
```bash
git add .
git commit -m "feat: Vercel fullstack deployment setup"
git push origin main
```

---

### Step 2: Vercel pe Import Karein
1. [vercel.com/new](https://vercel.com/new) pe jayein.
2. Apni GitHub repository select karein → **"Import"** click karein.
3. Vercel automatically detect karega ki yeh ek custom project hai.

---

### Step 3: Build Settings (Vercel Auto-detect Karega)
Vercel automatically `vercel.json` read karega. Koi manual changes nahi chahiye.  
Bas ek baar check karein:
- **Framework Preset**: `Other`
- **Build Command**: `cd frontend && npm install && npm run build` *(auto from vercel.json)*
- **Output Directory**: `frontend/dist` *(auto from vercel.json)*

---

### Step 4: ⭐ Environment Variables Add Karein (Most Important!)
**"Environment Variables"** section me yeh variables add karein:

| Variable | Value | Required? |
|---|---|---|
| `MONGO_URI` | `mongodb+srv://user:pass@cluster0.xyz.mongodb.net/spendflow` | ✅ Yes |
| `JWT_SECRET` | `any_long_random_secret_string_here` | ✅ Yes |
| `NODE_ENV` | `production` | ✅ Yes |
| `CLIENT_URL` | *(aapka Vercel URL, e.g. `https://spendflow.vercel.app`)* | Optional |

> ⚠️ `VITE_API_URL` **mat add karo** — frontend automatically relative `/api` paths use karta hai.

---

### Step 5: Deploy! 🎉
**"Deploy"** button dabao — ~2 min me aapki full app live ho jayegi!

Aapko milega: `https://your-project-name.vercel.app`

## 🐛 Common Issues

| Problem | Solution |
|---|---|
| `Cannot connect to MongoDB` | Check `MONGO_URI` env variable + Atlas Network Access |
| `404 on page refresh` | Already handled by `vercel.json` rewrites |
| `API not found` | Check `vercel.json` routes `/api/:path*` → `/api/index.js` |
| `CORS error` | Backend allows all `.vercel.app` origins by default |
